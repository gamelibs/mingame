# 核心公式与棋盘定义

## 棋盘坐标系

人生选择器使用 10×10 网格展示当前年龄可选的行为。

### 横轴 X（行为事件类型 L1 ~ L10）

横轴 10 格从左到右依次为行为类别，对应 `l1 ~ l10`：

```text
l1    l2    l3    l4    l5    l6    l7    l8    l9    l10
成长  教育  事业  投资  感情  家庭  社交  兴趣  风险  机遇
```

| 坐标 | 类别 | 含义 |
|---|---|---|
| l1 | 成长 | 基础生存、健康、自律、养生 |
| l2 | 教育 | 学习、知识、技能、传承 |
| l3 | 事业 | 工作、求职、创业、管理 |
| l4 | 投资 | 储蓄、股票、基金、房产、保险 |
| l5 | 感情 | 恋爱、婚姻、情感经营 |
| l6 | 家庭 | 陪伴、育儿、赡养、家庭投资 |
| l7 | 社交 | 交友、人脉、社区、志愿活动 |
| l8 | 兴趣 | 旅行、运动、艺术、娱乐 |
| l9 | 风险 | 危机、意外、疾病、失败事件 |
| l10 | 机遇 | 幸运、贵人、风口、正面事件 |

### 纵轴 Y（风险系数 N1 ~ N10）

纵轴表示风险等级，**从下到上递增**。`n1` 在棋盘最底部，`n10` 在棋盘最顶部：

```text
n10  极高风险  ← 顶部
n9
n8
n7
n6
n5   中等风险
n4
n3
n2
n1   极低风险  ← 底部
```

风险越高：
- 收益上限越高
- 失败惩罚越大
- 负面事件概率越高

### 坐标示例

- `l1_n1`：成长类、极低风险（如 睡觉、吃饭）
- `l2_n2`：教育类、低风险（如 上学、阅读）
- `l3_n7`：事业类、高风险（如 创业）
- `l9_n10`：风险类、极高风险（如 战争、地震）

> 代码内部使用 `grid[y-1][x-1]` 存储，其中 `y=1` 对应 n1（底部），`x=1` 对应 l1（成长）。终端版与 Web 版在视觉渲染时都必须将 n1 显示在底部、n10 显示在顶部。

## 年龄段类别开放规则

| 年龄段 | 开放类别 |
|---|---|
| 1-5 岁 | 成长、教育、家庭、兴趣、风险、机遇 |
| 6-12 岁 | 成长、教育、家庭、兴趣、社交、风险、机遇 |
| 13-18 岁 | + 感情、事业萌芽 |
| 19-30 岁 | + 事业、投资 |
| 31 岁以上 | 全部 10 类 |

## 结果计算公式

### 风险修正

```text
ResultScore = 行为收益 × 风险等级 × 当前属性修正 × 随机事件
```

### 结果状态

| 档位 | 说明 |
|---|---|
| 大成功 | 财富/影响力大幅提升，健康/幸福上升，死亡概率下降 |
| 成功 | 获得正常收益 |
| 普通 | 变化较小 |
| 失败 | 资源损失 |
| 大失败 | 重创：破产、重病、失业等 |

## 关键机制

- **成功链**：连续成功解锁高阶行为、降低死亡概率、提高幸运。
- **失败链**：连续失败导致可选行为减少、风险事件增加、资源获取降低。
- **生态平衡**：LifeBalance 衡量人生是否失衡，偏科会受到惩罚。
