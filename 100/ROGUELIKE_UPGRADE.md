# 人生选择器 Roguelike 视觉与叙事升级方案

> 目标：从「属性增长模拟器」升级为「一部自己参与选择的人生故事」。

---

## 一、核心定位变化

| 旧定位 | 新定位 |
|---|---|
| 后台管理风属性面板 | 人生卷轴 / 时间轴叙事 |
| 财富+10 / 健康-5 | 25岁你选择创业，成功率38%，成功获得第一桶金 |
| 单一网格选择 | 人生地图 + 事件卡 + 时间轴 |
| 8 维工具化属性 | 6 维人生属性 |

---

## 二、六维人生属性

替换原有的：财富、健康、知识、技能、社交、幸福、影响力、幸运

新的六维：

1. **财富** — 金钱与资产
2. **事业** — 由知识、技能、影响力合并，代表事业成就
3. **爱情** — 恋爱/婚姻/亲密关系状态
4. **家庭** — 子女、家庭关系、养老
5. **健康** — 身体与心理状态
6. **声望** — 社会地位、人脉、名声

隐藏属性保留：
- 生态平衡度（LifeBalance）
- 成功链 / 失败链
- 死亡概率

## 四、视觉主题：人生卷轴

### 色彩
- 背景：泛黄纸张 `#f5e6c8` 或羊皮纸纹理
- 文字：深褐/墨黑 `#3d2b1f`
- 强调：朱砂红 `#c45c48`、印章金 `#d4a574`
- 卡片：带阴影的纸张卡片
- 时间轴：墨迹线条

### 元素
- 卷轴边框 / 纸张纹理
- 事件卡牌带四角装饰
- 成就印章（圆形/方形红色印章样式）
- 人生节点用墨点或照片框
- 选择按钮做成「朱砂印」样式

## 五、叙事系统

### 行为/事件卡牌结构

```ts
interface NarrativeCard {
  title: string;           // "25岁 · 创业"
  story: string;           // "你决定辞去稳定工作，全身心投入创业..."
  successRate: number;     // 38
  successText: string;     // "获得第一桶金，公司初见起色"
  failureText: string;     // "被骗走全部积蓄，事业跌入谷底"
  successEffects: EffectSnapshot;
  failureEffects: EffectSnapshot;
}
```

### 执行流程

1. 显示事件卡：年龄 + 行为 + 故事 + 成功率
2. 玩家选择「执行」或「放弃」
3. 执行后播放结果叙事：成功/失败文案
4. 属性变化以叙事形式呈现（不是简单的 +10）
5. 重大事件在时间轴上点亮，显示印章

---

## 六、人生地图

- 左侧显示已走过的人生节点
- 每个节点是一个事件/选择
- 用线连接，形成人生路径
- 重大事件用大节点/特殊图标

---

## 七、时间轴

底部横向时间轴：
- 起点：出生
- 终点：死亡/当前年龄
- 每个点代表一年或一个重大事件
- 已发生的事件点可点击查看详情
- 当前年龄点高亮闪烁

---

## 八、关系网与成就

### 关系网
- 简单展示：父母、伴侣、子女、朋友、导师、对手
- 随人生事件动态变化
- 用小型人物图标表示

### 人生成就
- 印章形式展示
- 例如：「初恋」「百万富翁」「创业者」「长寿者」「传奇人生」
- 解锁条件基于最终属性或历史事件

---

## 九、重大人生事件标记

以下行为/事件标记为 majorLifeEvent：

- 恋爱、表白、结婚、离婚
- 生育、育儿
- 创业、开公司、上市准备
- 买房、投资股票、高杠杆投资
- 疾病、重病、意外
- 退休、临终安排

在地图和时间轴上用特殊图标/颜色显示。
