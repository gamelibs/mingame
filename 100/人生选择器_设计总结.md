# 人生选择器（Life Grid）设计总结文档

> 基于项目文档综合分析后的可执行设计方案
> 
> 核心公式：**人生 = 时间 × 选择 × 概率**

---

## 一、核心概念修正：10×10 网格的真正含义

### 1.1 网格不是按年龄分列

每一回合（每一年），整个 10×10 网格都用于展示当前年龄可选的行为池。

- **X 轴（l1 ~ l10）**：当前年龄可选行为的排列位置，即第 1 个选择项、第 2 个选择项……
- **Y 轴（n1 ~ n10）**：行为的风险等级，n1 风险最低，n10 风险最高

### 1.2 不同年龄的差异表现

| 年龄 | 可选行为数量 | 风险分布 | 网格表现 |
|---|---|---|---|
| 1 岁 | 3~5 个 | 全部集中在 n1~n3 | 只在最下面几行横向排列 |
| 10 岁 | 6~10 个 | n1~n4 |  occupy 下四行，横向展开 |
| 30 岁 | 20~30 个 | n1~n8 | 占据大部分网格，二维分布 |
| 70 岁 | 15~20 个 | n1~n6 | 偏向保守，分布在中下区域 |

### 1.3 行为在网格中的定位规则

```ts
function getBehaviorPosition(behavior, index, poolSize) {
  // Y 轴 = 风险等级
  const y = behavior.riskLevel;  // n1 ~ n10
  
  // X 轴 = 在同等风险行为中的排序
  // 同一风险等级的行为从左到右排列
  const sameRiskBehaviors = pool.filter(b => b.riskLevel === behavior.riskLevel);
  const x = sameRiskBehaviors.indexOf(behavior) + 1;  // l1 ~ l10
  
  return { x, y };
}
```

### 1.4 网格渲染逻辑

```ts
function renderGrid(age, availableBehaviors) {
  // 1. 初始化 10×10 空网格
  const grid = createEmptyGrid(10, 10);
  
  // 2. 按风险等级分组
  const grouped = groupByRiskLevel(availableBehaviors);
  
  // 3. 每组从左到右填充对应行
  for (let risk = 1; risk <= 10; risk++) {
    const behaviors = grouped[risk] || [];
    behaviors.slice(0, 10).forEach((b, index) => {
      grid[risk - 1][index] = b;  // row = risk-1, col = index
    });
  }
  
  return grid;
}
```

**关键表现**：
- 年龄越小，网格越空旷，只有底部低风险区有内容
- 年龄越大，网格越饱满，甚至出现多行填满的情况
- 玩家能直观看到「人生选择面随着年龄逐渐展开」

```ts
interface Behavior {
```

```ts
interface ChoiceRecord {
```

## 四、核心游戏循环

```
开始新回合
  │
  ▼
年龄 +1
  │
  ▼
根据年龄、财富、状态生成可选行为池
  │
  ▼
将行为池映射到 10×10 网格（按风险等级纵向分布）
  │
  ▼

  │
  ▼

  │
  ▼
确认执行，生成行为权重 t（0.1 ~ 1.0）
  │
  ▼
结算结果：ResultScore = 行为收益 × 风险等级 × 属性修正 × 随机因子
  │
  ▼
触发随机事件
  │
  ▼
更新玩家属性
  │
  ▼
更新生态平衡度 LifeBalance
  │
  ▼
更新成功链 / 失败链
  │
  ▼
死亡判定
  │   ├─ 命中 → 游戏结束，进入结算
  │   └─ 未命中 → 继续
  ▼
记录人生轨迹
  │
  ▼
检查特殊结局 / 最大年龄
  │
  ▼
下一回合
```

## 五、关键子系统设计

### 5.1 行为池生成系统

核心目标：**不同年龄显示不同数量和风险分布的行为，同时受财富影响并有保底机制**。

```ts
function generateBehaviorPool(state: PlayerState): Behavior[] {
  const { age, money, lifeBalance, successChain, failureChain } = state;
  
  // 1. 按年龄段过滤
  let candidates = behaviorDatabase.filter(b => 
    age >= b.minAge && age <= b.maxAge
  );
  
  // 2. 根据财富解锁更多行为
  const wealthBonus = Math.min(Math.floor(money / unlockThreshold), 5);
  const baseCount = getBaseCountByAge(age);  // 按年龄保底
  const maxCount = baseCount + wealthBonus;
  
  // 3. 失败链限制：只能选低风险、基础行为
  if (failureChain >= 3) {
    candidates = candidates.filter(b => b.riskLevel <= 3);
  }
  
  // 4. 成功链奖励：解锁高阶、高风险高收益行为
  if (successChain >= 3) {
    candidates = candidates.filter(b => 
      b.riskLevel >= 4 || b.unlockWealth <= money
    );
  }
  
  // 5. 按风险等级均匀采样，保证各风险区都有选择
  const pool = sampleByRiskLevel(candidates, maxCount);
  
  return pool;
}

function getBaseCountByAge(age: number): number {
  if (age <= 5) return 3;
  if (age <= 12) return 5;
  if (age <= 18) return 8;
  if (age <= 30) return 15;
  if (age <= 50) return 25;
  if (age <= 70) return 20;
  return 12;
}
```

**各年龄行为数量与风险上限（以 `src/data/age-config.ts` 为准）：**

| 年龄段 | 保底数量 | 财富加成后最大 | 风险上限 |
|---|---|---|---|
| 1-5 岁 | 4 | 5 | n3 |
| 6-12 岁 | 5 | 7 | n4 |
| 13-18 岁 | 6 | 9 | n5 |
| 19-30 岁 | 7 | 12 | n8 |
| 31-50 岁 | 7 | 13 | n9 |
| 51-70 岁 | 6 | 11 | n8 |
| 71 岁以上 | 5 | 8 | n6 |

> 注：网格只有 100 格，当行为数量超过 100 时，按风险等级优先级显示，高风险区可溢出到下一列或合并显示。

### 5.2 结果计算系统

```ts
function resolveResult(
  behavior: Behavior,
  riskLevel: number,
  state: PlayerState
): ResultType {
  // 1. 行为基础收益
  const baseReward = behavior.rewardLevel;
  
  // 2. 风险等级倍数
  const riskMultiplier = riskLevel;
  
  // 3. 属性修正
  const attrMultiplier = calcAttrBonus(behavior, state);
  
  // 4. 随机因子：0.5 ~ 2.0，幸运可提升上限
  const luckBonus = state.luck * 0.01;
  const randomFactor = 0.5 + Math.random() * 1.5 + luckBonus;
  
  // 5. 生态平衡惩罚
  const balancePenalty = state.lifeBalance < 30 ? 0.7 : 1.0;
  
  // 6. 失败链惩罚 / 成功链加成
  const chainFactor = state.failureChain > 0 
    ? Math.pow(0.9, state.failureChain)
    : Math.pow(1.05, state.successChain);
  
  const score = baseReward * riskMultiplier * attrMultiplier 
              * randomFactor * balancePenalty * chainFactor;
  
  return mapScoreToResult(score, behavior.failureLevel);
}
```

**结果档位判定：**

| 档位 | 判定条件 | 属性影响 |
|---|---|---|
| 大成功 | score ≥ failureLevel × 3 | 财富、影响力大幅提升，健康/幸福上升，死亡概率下降 |
| 成功 | score ≥ failureLevel × 1.5 | 正常收益 |
| 普通 | failureLevel × 0.5 ≤ score < 1.5 | 变化较小 |
| 失败 | score < failureLevel × 0.5 | 资源损失，幸福下降 |
| 大失败 | score < 0 或极低 | 重创：破产、重病、失业等 |

### 5.3 属性修正计算

不同行为受不同属性加成：

```ts
function calcAttrBonus(behavior: Behavior, state: PlayerState): number {
  const tagBonus = {
    '知识': state.knowledge * 0.01,
    '技能': state.skill * 0.01,
    '财富': state.money * 0.0001,
    '社交': state.social * 0.01,
    '健康': state.health * 0.01,
    '影响力': state.influence * 0.01
  };
  
  let bonus = 1.0;
  behavior.tags.forEach(tag => {
    if (tagBonus[tag]) bonus += tagBonus[tag];
  });
  
  return Math.max(0.5, bonus);
}
```

### 5.4 生态平衡度系统

```ts
function updateLifeBalance(
  state: PlayerState,
  behavior: Behavior,
  result: ResultType
): void {
  let delta = behavior.balanceEffect;
  
  // 连续重复同类行为降低平衡
  const last = state.history[state.history.length - 1];
  if (last && last.behaviorId === behavior.id) {
    delta -= 3;
  }
  
  // 结果影响
  if (result === 'bigSuccess') delta += 5;
  if (result === 'success') delta += 2;
  if (result === 'failure') delta -= 3;
  if (result === 'bigFailure') delta -= 10;
  
  // 极端属性失衡惩罚
  if (state.money > state.health * 1000) delta -= 2;  // 有钱但健康差
  if (state.happy < 20) delta -= 2;
  
  state.lifeBalance = clamp(state.lifeBalance + delta, 0, 100);
}
```

**平衡度效果：**

| 范围 | 效果 |
|---|---|
| 0 ~ 30 | 高风险：结果恶化，危机事件概率 +30%，死亡概率 +20% |
| 30 ~ 70 | 正常 |
| 70 ~ 100 | 增益：结果向好，幸运事件概率 +20%，属性恢复加速 |

### 5.5 成功链与失败链系统

```ts
function updateChains(state: PlayerState, result: ResultType): void {
  if (['bigSuccess', 'success'].includes(result)) {
    state.successChain++;
    state.failureChain = 0;
    state.luck = Math.min(state.luck + 1, 100);
    state.deathRate *= 0.95;
  } else if (['bigFailure', 'failure'].includes(result)) {
    state.failureChain++;
    state.successChain = 0;
    state.luck = Math.max(state.luck - 2, 0);
    state.deathRate *= 1.1;
  } else {
    // 普通结果缓慢衰减
    state.successChain = Math.max(state.successChain - 1, 0);
    state.failureChain = Math.max(state.failureChain - 1, 0);
  }
}
```

**连锁效果：**

| 连锁类型 | 持续 3 次 | 持续 5 次 | 持续 8 次 |
|---|---|---|---|
| 成功链 | 解锁高阶行为 | 死亡概率显著降低 | 触发隐藏传奇事件 |
| 失败链 | 可选行为减少 | 只能选低风险行为 | 强制进入危机模式 |

### 5.6 死亡判定模型

```ts
function checkDeath(state: PlayerState): boolean {
  // 1. 基础年龄死亡率
  const baseRate = getBaseDeathRateByAge(state.age);
  
  // 2. 健康修正
  const healthFactor = 1 + (100 - state.health) / 40;
  
  // 3. 生态平衡修正
  const balanceFactor = 1 + (100 - state.lifeBalance) / 80;
  
  // 4. 失败链修正
  const chainFactor = 1 + state.failureChain * 0.15;
  
  // 5. 高风险行为修正
  const lastRisk = state.history[state.history.length - 1]?.y || 1;
  const riskFactor = 1 + (lastRisk - 1) * 0.05;
  
  const finalRate = baseRate * healthFactor * balanceFactor 
                  * chainFactor * riskFactor;
  
  return Math.random() * 100 < finalRate;
}
```

**基础年龄死亡率表：**

| 年龄 | 基础死亡率 |
|---|---|
| 1 岁 | 0.01% |
| 10 岁 | 0.02% |
| 20 岁 | 0.05% |
| 40 岁 | 0.3% |
| 60 岁 | 2% |
| 80 岁 | 15% |
| 100 岁 | 70% |
| 110 岁 | 95% |

```ts
function calcEventWeight(event: GameEvent, state: PlayerState): number {
  let weight = event.weight;
  
  if (event.type === 'lucky') {
    weight *= (1 + state.luck * 0.02);
    weight *= (1 + state.successChain * 0.1);
  }
  
  if (event.type === 'crisis') {
    weight *= (1 + state.failureChain * 0.15);
    weight *= (1 + (100 - state.lifeBalance) * 0.01);
  }
  
  return weight;
}
```

```ts
function evaluateLife(state: PlayerState): string {
  if (state.money > 1000000 && state.happy > 70) return "富有的一生";
  if (state.influence > 80 && state.successChain > 10) return "传奇的一生";
  if (state.lifeBalance > 80 && state.happy > 80) return "幸福的一生";
```

## 九、保存 / 加载 / 回放系统

### 9.1 人生数据格式

每场人生可导出为 `LifeData` JSON，核心字段：

```ts
interface SavedLifeData {
  version: number;              // 数据版本，当前为 1
  config: {
    mode: 'modern' | 'apocalypse';
    maxAge: number;
  };
  records: ChoiceRecord[];      // 每一年选择记录
  snapshots: PlayerState[];     // snapshots[0] 为初始状态，snapshots[i+1] 为第 i 条记录执行后状态
  savedAt: string;              // ISO 导出时间
}
```

### 9.2 保存

Web 版支持两种保存方式：

- **本地存档槽**：通过 `life-storage.ts` 将 `SavedLifeData` 写入 `localStorage`，可保存多个人生并随时读取/删除。
- **文件导出**：通过 `controller.exportLifeData()` 生成 JSON 字符串，浏览器触发下载 `life-data.json`。

脚本 `scripts/generate-sample-life.ts` 可生成 120 年示例人生并写入 `public/sample-life.json`，构建时自动复制到 `dist-web/sample-life.json`。

### 9.3 加载

`controller.importLifeData(json)` 校验：

- `version` 必须匹配
- `config.mode` 合法
- `snapshots.length === records.length + 1`
- 所有 `behaviorId` 存在于当前行为库

校验失败返回 `null`；校验通过后返回 `SavedLifeData`，随后调用 `controller.startReplay(data)` 进入回放模式。

### 9.4 回放

`controller.startReplay(data)` 将状态重置为 `snapshots[0]`，之后逐年调用 `controller.replayStep()`：

1. 读取当前索引对应的记录
2. 将状态精确恢复为 `snapshots[replayIndex + 1]`
3. 逐步重建 `history` 与日志
4. 索引 +1

回放不重新随机判定，因此回放结束后所有属性与原人生的最终快照完全一致。

## 十二、关键设计亮点

1. **风险可视化**：Y 轴直接对应风险等级，玩家一眼就能看出「越往上越危险，收益也越高」。
2. **年龄展开感**：低龄时网格空旷、低风险；成年时网格饱满、选择丰富，形成强烈的人生成长感。
3. **连锁反馈**：成功和失败都会自我强化，避免玩家无脑选同一类行为。
4. **隐性平衡**：LifeBalance 作为隐藏裁判，防止玩家过度偏科（如只赚钱不养生）。
5. **保底机制**：即使失败链缠身，也保留最低数量可选行为，避免游戏锁死。

## 十三、待确认事项

1. 10×10 网格超过 100 个行为时，如何处理溢出？建议方案：同风险等级横向最多 10 个，超出时合并为「更多」入口或滚动显示。
2. 行为权重 t（0.1~1.0）如何生成？建议方案：玩家通过倒计时内点击确认的时机决定，越早确认 t 越高，增加操作紧张感。
3. 是否需要多题材切换？现代社会库和末世库可作为两个独立模式。
