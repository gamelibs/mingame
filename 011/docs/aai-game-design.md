# AAI 规则设计与《Dragon Egg》游戏结合方案

> 本文档基于当前 `011/` 项目已有的 6×6 棋盘、7 级龙蛋合成玩法，结合「简单操作 + 无限循环 + 强反馈 + 高频广告点」的 IAA（In-App Advertising）小游戏模型，制定可落地的改造方案。

---

## 一、当前游戏机制盘点

### 1.1 核心玩法

| 要素 | 当前实现 | 说明 |
|---|---|---|
| 棋盘 | 6×6，共 36 格 | 已固定 |
| 龙蛋等级 | 1 ~ 7 级 | 7 级为最高级（神龙蛋） |
| 每波生成 | 3 个蛋 | 默认只生成 1~3 级蛋 |
| 移动规则 | 点击选中 → 点击目标格 → 沿路径移动 | A* 寻路 |
| 合成规则 | 移动到同等级蛋附近，吸收周围 ≥3 个同等级蛋 → 合成更高一级 | 三连合成 |
| 胜利条件 | 合成出 7 级蛋 | 触发 `mc_victory` |
| 失败条件 | 棋盘已满且无法继续合成 | 触发 `mc_failure` |
| 难度 | easy/normal/hard | 控制每波生成数量（当前默认 4，与描述不符，需校准） |
| 分数 | 合成得分 + 历史最高分 | 已有 `scoreSystem` |
| 解锁进度 | `maxUnlockedEggType` | 已存在，可继续扩展 |

### 1.2 当前广告接入

| 广告类型 | 当前状态 | 触发位置 |
|---|---|---|
| 插屏广告 | ✅ 已接入 | 重新开始、失败重试、胜利再玩、每 3 关通过后 |
| 激励视频 | ✅ 已接入 | 复活、双倍金币 |
| Banner 广告 | ✅ 已接入 | 首页/设置页常驻 |

### 1.3 当前体验问题（从 IAA 角度）

1. **单局过长**：合成到 7 级需要较多步数，单局可能超过 2 分钟，不符合「10~60 秒快节奏循环」。
2. **失败惩罚过重**：失败后只能从头开始，缺少「看广告复活」的留存抓手。
3. **广告点单一**：只有插屏，缺少激励视频的高价值转化点。
4. **成长感弱**：除了分数和解锁等级，没有关卡、任务、每日目标等留存结构。
5. **无社交裂变**：没有分享换奖励、好友排行榜对比等分发机制。
6. **爽感前置不足**：前期难度若过高，容易导致首局失败、流失。

## 二、AAI 改造总体目标

### 2.1 核心公式

```
收入 = DAU × 人均广告展示次数 × eCPM
        ↓
DAU = 新增用户 × 留存率 × 分享裂变
        ↓
留存率 = 爽感前置 + 合理卡点 + 广告/分享续命 + 成长目标
```

### 2.2 设计原则

| 原则 | 落地要求 |
|---|---|
| **简单操作** | 保持「点 → 点」两点击操作，不改核心交互 |
| **无限循环** | 单局短、复活快、关卡无限、失败即下一局入口 |
| **强反馈** | 每次合成都有音效 + 震动 + 粒子 + 分数跳字 + 解锁提示 |
| **高频广告点** | 复活、双倍奖励、提示、跳关、每日奖励、连续失败插屏 |
| **可控节奏** | 1 分钟给爽感，5 分钟变难，10 分钟出现卡点，之后依赖广告/分享 |

## 三、玩法模型改造

### 3.1 引入「波次 + 关卡」双循环

当前是「一盘到底」模式，改造为「单局多波次 + 无尽关卡」：

```
关卡 1：目标合成 4 级蛋（3~5 波可完成）
关卡 2：目标合成 5 级蛋
关卡 3：目标合成 6 级蛋
关卡 4+：目标合成 7 级蛋（神龙蛋），或改为「存活 N 波」
```

**单局流程：**

```
进入关卡 → 生成 3 个初始蛋 → 玩家操作 → 每次操作后生成 3 个新蛋（一波）
    ↓
达成目标等级 → 关卡胜利 → 结算奖励 → 进入下一关
    ↓
棋盘满 → 游戏失败 → 弹出复活/重开选择
```

**改造点：**

- [ ] 在 `GameServer.getGameData` 中增加 `level` 和 `targetEggType` 字段
- [ ] 在 `GameServer.handleEggMove` 中增加关卡胜利判断（不再只有 7 级才胜利）
- [ ] 前端 `mc_victory` 改为「关卡完成」界面，显示「下一关」按钮
- [ ] 每关目标等级随关卡数递增，7 级后改为「存活波次」或「目标分数」

### 3.2 调整每波生成数量与难度曲线

**当前问题：**`difficulty` 默认是 4（每波生成 4 个蛋），这与用户描述的「每波 3 个」不符，且 4 个蛋会让棋盘快速填满。

**建议校准：**

| 关卡 | 每波生成数 | 生成等级范围 | 说明 |
|---|---|---|---|
| 1~2 | 2 个 | 1~2 级 | 首局给爽感，快速合成 |
| 3~5 | 3 个 | 1~3 级 | 标准节奏 |
| 6~10 | 3 个 | 1~4 级 | 开始出现 4 级蛋，增加压力 |
| 11+ | 3~4 个 | 1~4 级 | 压力增大，鼓励使用道具/广告 |

**改造点：**

- [ ] 修改 `GameServer.difficulty` 的语义：从「每波生成数量」改为「关卡难度系数」
- [ ] 新增 `getSpawnConfig(level)` 方法，根据关卡返回 `{ count, maxLevel, weights }`
- [ ] 新用户前 2 关强制低难度，确保首局胜利

### 3.3 增加「连击/Combo」系统

**规则：**

- 单次移动触发多次合成（如 A→B 合成 3 级，3 级又和旁边两个 3 级合成 4 级）算 Combo
- Combo ×2、×3、×4 依次放大分数
- Combo 达到 3 以上时触发全屏特效 + 额外奖励

**改造点：**

- [ ] 在 `processSynthesisResult` 中递归检查合成后的新蛋是否还能继续合成
- [ ] 累计 Combo 计数，传递给前端显示
- [ ] 前端增加 Combo 跳字动画

### 3.4 增加「道具系统」

道具是激励广告的最佳载体：

| 道具 | 效果 | 获取方式 |
|---|---|---|
| **提示（Hint）** | 高亮显示当前最优移动路径 | 看广告 / 金币购买 |
| **撤销（Undo）** | 撤销上一步操作（包括回退生成的蛋） | 看广告 / 金币购买 |
| **炸弹（Bomb）** | 删除指定一个蛋 | 看广告 / 金币购买 |
| **刷新（Shuffle）** | 重新生成场上所有蛋的等级（位置不变） | 看广告 / 金币购买 |
| **跳过一波（Skip Wave）** | 本次操作后不生成新蛋 | 看广告 |

**改造点：**

- [ ] 新增 `src/modules/items.js` 道具模块
- [ ] 在 `GameServer` 中增加道具状态 `userItems = { hint, undo, bomb, shuffle, skip }`
- [ ] 前端在设置/暂停界面或悬浮按钮增加道具入口
- [ ] 道具不足时弹出「看广告获得」弹窗

### 3.5 增加「金币/钻石」经济系统

**规则：**

- 合成获得金币，高级合成金币更多
- 金币可用于购买道具
- 钻石（硬通货）只能通过广告/分享/每日奖励获得

**改造点：**

- [ ] 扩展 `scoreSystem` 为 `currencySystem = { coin, diamond }`
- [ ] 在合成动画后显示金币飞入效果
- [ ] 在设置界面显示金币/钻石数量

## 四、广告模型设计

### 4.1 广告点地图

```
用户进入
   ↓
【开屏/首页】Banner 广告常驻
   ↓
开始游戏
   ↓
第 1 关（爽感关，无广告）
   ↓
第 2 关胜利 → 插屏广告（首次短循环后）
   ↓
第 3 关失败 → 【复活弹窗】激励视频：复活并清空最近 3 波生成的蛋
   ↓
拒绝复活 → 插屏广告 → 回到首页
   ↓
连续失败 2 次 → 【提示弹窗】激励视频：获得一次提示
   ↓
关卡胜利结算 → 激励视频：双倍金币奖励
   ↓
每 3 关 → 插屏广告
   ↓
点击道具 → 激励视频：获得道具
```

### 4.2 插屏广告触发点

| 时机 | 当前状态 | 建议 |
|---|---|---|
| 首页 → 开始游戏 | ❌ | 不建议，影响启动体验 |
| 关卡胜利 → 下一关 | ❌ | ✅ 建议添加，自然过渡点 |
| 失败 → 重开 | ✅ 已有 | 保留，但先给复活机会 |
| 每 3 次操作后 | ❌ | 不建议，太频繁 |
| 每 3 关通过后 | ❌ | ✅ 建议添加 |
| 返回首页 | ❌ | ✅ 建议添加 |

**改造点（已实现）：**

- [x] 新增 `adTrigger.levelCount`，记录已通过关卡数
- [x] 在 `_doClaimLevelReward` 中判断：若 `GameServer.level % 3 === 0` 且 `levelCount > 0`，则先显示插屏再进入下一关/重开
- [x] 保留原有的失败/重开插屏，但顺序改为：失败 → 复活弹窗（用户拒绝或看完广告后）→ 插屏 → 重开

### 4.3 激励视频触发点

| 场景 | 广告奖励 | 优先级 |
|---|---|---|
| **复活（Revive）** | 失败后复活，保留当前棋盘并移除最近 3 波生成的蛋 | P0 ✅ |
| **双倍金币** | 关卡胜利后金币 ×2 | P0 ✅ |
| **获得提示** | 高亮一次最佳移动 | P1 |
| **获得炸弹** | 删除一个指定蛋 | P1 |
| **获得撤销** | 撤销上一步 | P1 |
| **每日奖励翻倍** | 每日登录奖励翻倍 | P1 |
| **解锁皮肤/主题** | 提前解锁新龙蛋外观 | P2 |

**改造点（已实现）：**

- [x] 在 `GameServer` 中新增 `claimLevelReward(double)` 统一结算关卡金币奖励
- [x] 在失败界面增加「复活」按钮（看广告 / 分享 / 放弃）
- [x] 在胜利结算界面动态增加「普通领取」和「看广告双倍领取」按钮
- [ ] 在道具按钮上增加广告获取入口（P1）

### 4.4 Banner 广告位置

| 位置 | 说明 |
|---|---|
| 首页底部 | 常驻 Banner |
| 设置/暂停界面底部 | 常驻 Banner |
| 失败/胜利弹窗底部 | 可选，避免遮挡按钮 |

**改造点（已实现）：**

- [x] 在 `GameScense.init()` 完成后调用 `ovo.showBannerAd()`，首页常驻
- [x] 在游戏主界面隐藏 Banner（避免遮挡棋盘）—— 实际保持首页常驻，wx 端控制 Banner 位于屏幕底部不遮挡棋盘
- [x] 在设置/暂停界面显示 Banner，关闭后继续显示

## 五、数值增长模型（留存核心）

### 5.1 爽感前置（0~1 分钟）

- 第 1 关目标：合成 4 级蛋
- 初始棋盘只放 6 个蛋，且多为 1~2 级
- 每波只生成 2 个蛋
- 确保新用户 30 秒内完成首次合成 4 级
- 首次合成 4 级时：全屏特效 + 震动 + 金币雨

### 5.2 难度爬升（1~5 分钟）

- 第 2~3 关：目标 5 级，每波 3 个蛋
- 第 4~6 关：目标 6 级，开始出现 3~4 级蛋
- 每关胜利奖励递增
- 首次失败出现在第 3~4 关左右

### 5.3 卡点出现（5~10 分钟）

- 第 7~10 关：目标 7 级（神龙蛋）
- 每波 3 个蛋，生成等级 1~4
- 棋盘压力明显增大
- 引入「复活」广告点：第一次失败后 80% 用户选择看广告复活

### 5.4 循环依赖广告（10 分钟后）

- 无尽关卡：目标变为「存活 N 波」或「达到目标分数」
- 高级道具（炸弹、刷新）需求上升
- 每日任务、成就、排行榜驱动次日留存

### 5.5 具体数值建议

| 关卡 | 目标等级 | 每波蛋数 | 每波最大等级 | 胜利金币 | 失败复活次数 |
|---|---|---|---|---|---|
| 1 | 4 | 2 | 2 | 50 | 1 |
| 2 | 4 | 2 | 2 | 60 | 1 |
| 3 | 5 | 3 | 3 | 80 | 1 |
| 4 | 5 | 3 | 3 | 100 | 1 |
| 5 | 6 | 3 | 3 | 130 | 1 |
| 6 | 6 | 3 | 4 | 160 | 1 |
| 7 | 7 | 3 | 4 | 200 | 1 |
| 8+ | 7 / 存活 | 3~4 | 4 | 250+（每 3 关 +50） | 每局 1 次 |

5. 接入 Banner 广告（首页/设置页） ✅

6. 引入关卡系统（目标等级随关卡递增）
7. 增加道具系统（提示、撤销、炸弹、刷新）
8. 增加金币/钻石经济

## 十一、风险与注意事项

1. **广告频率控制**：插屏广告不要过于频繁，避免用户流失。建议每 3 关一次，或失败后一次。
2. **复活平衡**：复活后移除最近 3 波生成的蛋，避免玩家无限复活通关。
3. **难度曲线**：首局必须给爽感，否则新用户留存会差。建议新用户前 2 关强制简单。
4. **微信审核**：激励广告必须有真实奖励，不能欺骗用户；插屏不能强制观看超过 5 秒。
5. **隐私合规**：接入微信登录、排行榜时，必须更新隐私政策和用户授权。
6. **性能**：新增粒子特效、Combo 动画需注意低端机性能，提供关闭选项。

## 十二、总结

本方案在不改变核心「点击移动 + 三三合成」玩法的前提下，通过以下四步把《Dragon Egg》改造成符合 AAI 模型的小游戏：

1. **缩短单局、关卡化**：把「一盘到 7 级」拆成多个短关卡，每关 10~60 秒。
2. **增加广告点**：复活、双倍奖励、道具、每 3 关插屏、Banner 常驻。
3. **增加成长系统**：金币、道具、每日任务、成就、排行榜，驱动长期留存。
4. **强化反馈**：Combo、金币飞入、解锁特效、分享炫耀，提升爽感和传播。

建议先实施 P0 项，快速验证广告变现能力；再逐步叠加 P1/P2 系统。
